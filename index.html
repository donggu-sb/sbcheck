취합 (담당자용)

      
점검자들이 보낸 결과 CSV 여러 개를 한꺼번에 골라 하나로 합칩니다. 같은 주소(동 구분 포함)가 여러 개면 수정 시각이 늦은 것을 남깁니다. 합친 CSV와 함께, 점검 완료 건으로 대구시 「분기별 점검양식」과 같은 모양의 엑셀 파일도 만듭니다.

      
      

      
당일 배부 (방문 예정일 기준)

      
사전 확인에서 「방문 예정일시」와 「배정 점검자」를 정한 건물을 날짜별로 모아, 그날 들고 갈 일정표와 점검표(사전 정보가 채워진 빈 점검표), 앱용 배정 파일을 만듭니다.

      

      
      

      

      
배정 파일 만들기

      
사전 확인 때 「배정 점검자」를 적은 건물을 점검자별 파일로 저장합니다. 점검자는 휴대폰에서 「백업 불러오기」로 이 파일을 열면 대장 정보와 사전 확인 메모가 담긴 목록을 받습니다.
